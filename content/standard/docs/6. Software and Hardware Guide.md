# 6. Software and Hardware Guide

## 6.1 micro:bit Board Overview

### 6.1.1 Overview

Led by the BBC in the UK and co-developed with Microsoft, Samsung, and ARM, the micro:bit is a pocket-sized microcomputer designed for youth programming education, measuring only half the size of a standard credit card. Despite its compact footprint, it integrates Bluetooth, an accelerometer, a compass, three pushbuttons, a 5×5 LED matrix display, and a microphone.

The micro:bit features extensive open-source libraries and engaging project solutions. Access the platform directly by clicking [Microsoft MakeCode for micro:bit](https://makecode.microbit.org/), or copy the URL below into any web browser to explore the website:

```
https://makecode.microbit.org/
```

| :---: | :--- |

## 6.2 Nexbit AI Chassis Board

### 6.2.1 Overview

The Nexbit AI chassis features a compact form factor built on an immersion gold ENIG PCB. It integrates an array of electronic components, including a 4-channel line follower sensor with tuning knobs, RGB LEDs, DC geared motors, and an infrared receiver. These components support core functions such as line-following navigation, status indication, propulsion, and signal reception. The chassis also provides multiple servo ports and sensor expansion ports to support secondary development and hardware expansion.

## 6.6 WonderLLM Module

<a id="section-7-6-1"></a>

### 6.6.1 Module Overview

#### (1) Module Introduction

The WonderLLM is an intelligent multimodal AI module powered by a high-performance ESP32-S3 chip. It integrates a 2MP camera, a microphone, a high-resolution display, an onboard speaker, and a CI1302 voice recognition chip, seamlessly combining multimodal AI capabilities across text, speech, and vision.

Designed for intuitive operation, the module serves as a super brain when paired with robotic platforms. It accurately interprets complex commands and endows robots with advanced perception, reasoning, and execution capabilities, delivering a responsive and natural human-robot interaction experience.

<img src="../_static/media/chapter_7/section_5/media/subsection_1/1.png" class="common_img" style="width:300px;">

#### (2) Operating Principle

* The module uses command wake-up mode. Speaking the wake-up word activates WonderLLM to enable human-robot interaction. English recognition requires flashing the English voice recognition firmware. After switching to the English firmware, the wake-up keyword becomes **"Hello Hiwonder"**.

* Once the module detects the wake-up word, the buzzer emits a beep, indicating readiness for interaction. The module supports English conversations, automatically detecting and switching the language based on incoming speech. If no voice input is detected within 1 minute, the module enters sleep mode and requires waking up before further interaction.

#### (3) Hardware Port Description

<img src="../_static/media/chapter_7/section_5/media/subsection_1/2.png" class="common_img" style="width:500px;">

| Number | Description                                                  |
| :----: | :----------------------------------------------------------- |
|   1    | Top Type-C port: Used for flashing program firmware to the ESP32-S3 chip |
|   2    | Bottom Type-C port: Used for flashing voice recognition firmware to the CI1302 chip |
|   3    | 4-pin I2C port: Available for secondary development          |
|   4    | Capacitive touch screen: Used for screen display and volume adjustment |
|   5    | Left pushbutton: Used for toggling expressions and chat modes |
|   6    | HD camera: Captures real-time images                         |
|   7    | Right pushbutton: Used for network configuration and interactive control |

#### (4) Precautions

1. Supply power using a 5 V voltage source. Voltages outside this specification may damage the module.

2. Operate the module in a quiet environment, as background noise can degrade recognition performance.

3. Speak clearly and at a moderate pace, maintaining a distance within 5 m of the module.

### 6.6.8 Free Chat

#### (1) General Operation

1. Once the module is powered on and connected to the network, wake the module by **speaking the wake-up word or short-pressing the right button** to enter chat mode.

3. After each conversational turn (including initial wake-up), the module continues listening. If no speech is detected for 2 consecutive minutes, listening terminates automatically, and the model announces a farewell phrase in the chat interface. To resume interaction, wake the module again by **speaking the designated wake-up word or short-pressing the right button**.
