6. Software and Hardware Guide ​

6.1 micro:bit Board Overview ​

6.1.1 Overview ​

Led by the BBC in the UK and co-developed with Microsoft, Samsung, and ARM, the micro:bit is a pocket-sized microcomputer designed for youth programming education, measuring only half the size of a standard credit card. Despite its compact footprint, it integrates Bluetooth, an accelerometer, a compass, three pushbuttons, a 5×5 LED matrix display, and a microphone.

The micro:bit features extensive open-source libraries and engaging project solutions. Access the platform directly by clicking Microsoft MakeCode for micro:bit, or copy the URL below into any web browser to explore the website:

https://makecode.microbit.org/

6.2 Nexbit AI Chassis Board ​

6.2.1 Overview ​

The Nexbit AI chassis features a compact form factor built on an immersion gold ENIG PCB. It integrates an array of electronic components, including a 4-channel line follower sensor with tuning knobs, RGB LEDs, DC geared motors, and an infrared receiver. These components support core functions such as line-following navigation, status indication, propulsion, and signal reception. The chassis also provides multiple servo ports and sensor expansion ports to support secondary development and hardware expansion.

6.5.3 4-Channel Line Follower Sensor ​

6.6 WonderLLM Module ​

6.6.1 Module Overview ​

(1) Module Introduction ​

The WonderLLM is an intelligent multimodal AI module powered by a high-performance ESP32-S3 chip. It integrates a 2MP camera, a microphone, a high-resolution display, an onboard speaker, and a CI1302 voice recognition chip, seamlessly combining multimodal AI capabilities across text, speech, and vision.

Designed for intuitive operation, the module serves as a super brain when paired with robotic platforms. It accurately interprets complex commands and endows robots with advanced perception, reasoning, and execution capabilities, delivering a responsive and natural human-robot interaction experience.

(2) Operating Principle ​

  • The module uses command wake-up mode. Speaking the wake-up word activates WonderLLM to enable human-robot interaction. English recognition requires flashing the English voice recognition firmware. After switching to the English firmware, the wake-up keyword becomes "Hello Hiwonder".

  • Once the module detects the wake-up word, the buzzer emits a beep, indicating readiness for interaction. The module supports English conversations, automatically detecting and switching the language based on incoming speech. If no voice input is detected within 1 minute, the module enters sleep mode and requires waking up before further interaction.

(3) Hardware Port Description ​

NumberDescription
1Top Type-C port: Used for flashing program firmware to the ESP32-S3 chip
2Bottom Type-C port: Used for flashing voice recognition firmware to the CI1302 chip
34-pin I2C port: Available for secondary development
4Capacitive touch screen: Used for screen display and volume adjustment
5Left pushbutton: Used for toggling expressions and chat modes
6HD camera: Captures real-time images
7Right pushbutton: Used for network configuration and interactive control

(4) Precautions ​

  1. Supply power using a 5 V voltage source. Voltages outside this specification may damage the module.

  2. Operate the module in a quiet environment, as background noise can degrade recognition performance.

  3. Speak clearly and at a moderate pace, maintaining a distance within 5 m of the module.

6.6.2 Module Configuration ​

(1) Powering On ​

  1. The module supports power input through any of the following ports: ① Top Type-C port, ② Bottom Type-C port, or ③ 4-pin I2C port. Connect an external power supply to any of these ports, and the module powers on automatically.
  1. After powering on, the screen displays Hiwonder, indicating that loading is in progress. Once the screen displays the device hotspot name and browser configuration URL accompanied by a voice broadcast, proceed to 6.6.2 (2) Module Networking to configure the Wi-Fi connection.
  1. After completing network configuration, bind the module to a platform agent. When the screen displays the Device ID and platform binding URL while announcing the binding verification code, follow 6.6.2 (3) Device Binding to complete the process.
  1. Upon powering on a previously bound device, the screen displays Hiwonder while the module attempts to connect automatically using saved Wi-Fi credentials. If the connection fails, the screen displays the device hotspot name and browser configuration URL along with voice prompts. Follow 6.6.2 (2) Module Networking to configure available Wi-Fi credentials for the current environment.
  1. When the device is already bound and the configured Wi-Fi network is available, the screen shows Hiwonder during initialization, completes the connection, and transitions to the expression interface. At this stage, all module settings are operational. Wake the module to begin human-robot interaction.

(2) Module Networking ​

  • Operation Overview

The module enters network configuration mode under three conditions: ① Initial operation or following firmware flashing when no valid Wi-Fi credentials exist in memory. ② No matching hotspot is available in the current environment. ③ Manual entry triggered by long-pressing Button B.

  • Operation Steps
  1. The module initiates network connection upon powering on. The screen displays the device hotspot name and browser configuration URL accompanied by a voice broadcast. The module activates its built-in hotspot for configuration. Hotspot names vary across devices and follow the format "Robot-xxxx". The following guide uses hotspot Robot-B7B9 as an example.
  1. Search for and connect to the corresponding hotspot using a computer or smartphone. The hotspot requires no password.
  1. Click the hyperlink Network Configuration or copy the following URL into any browser to open the configuration portal:
py
http://192.168.4.1
  1. Enter the target Wi-Fi name in field ① and the corresponding password in field ②. Click Connect in field ③. The module attempts to locate and connect to the specified network in the current environment.
  1. If the following prompt appears, the network could not be located in the current environment, or the password was incorrect. Re-enter the credentials.
  1. When the following prompt appears, the module has connected successfully to the hotspot. The module restarts automatically and connects to the specified network.

NOTE

  • Do not enter hotspots that cannot be scanned in the current environment, have excessively weak signals, or lack Internet connectivity.

  • If network credentials were saved previously, newly saved hotspot information coexists with existing profiles. Upon subsequent power-ups, the module checks stored profiles sequentially in order of storage to attempt a connection.

  • If the prompt "Error: Failed to check for new version, will retry in xx seconds" appears after network configuration, the hotspot may lack Internet access or provide poor connection quality. Switch to a reliable network.

  • Entering Configuration Mode Manually

  1. The WonderLLM module supports manual entry into configuration mode to accommodate specific network selection requirements.

  2. Procedure: When the module is powered on, long-press the right button to send a restart command. The screen turns off upon receiving the command. Continue holding the button. As the module restarts and begins connecting to the network, a white circular progress bar appears on screen. Upon detecting the long-press on the right button, the module halts external network matching and enters configuration mode directly. Release the button at this point.

  3. Existing hotspot configuration profiles remain intact upon entering configuration mode. Access the network configuration portal or short-press the right button to exit configuration mode.

  4. After exiting configuration mode, the module continues attempting connections based on saved network profiles. If no connection can be established, it re-enters configuration mode.

  • Managing Saved Wi-Fi Profiles
  1. While the module is in configuration mode, connect to its hotspot and open the configuration portal to view all saved Wi-Fi profiles, if configured previously, as shown below:
  1. Click the delete icon next to any saved profile to remove it. Click the up-arrow icon to raise its connection priority during matching, with priority decreasing from top to bottom.

(6) Device Restarting ​

  1. The module supports manual rebooting while powered on. Two methods are available without disconnecting the power supply: ① Long-press the left button, Button A, or ② Long-press the right button, Button B.

  2. When detecting a long-press restart command, the module shuts down and restarts automatically. The screen turns off immediately. Release the button at this point. The module powers on shortly after.

  3. When restarting via long-pressing the right button, Button B, failing to release the button promptly upon reboot may cause the module to enter configuration mode by mistake. Therefore, rebooting via the left button is recommended.

6.6.4 Chat Mode ​

(1) Mode Overview ​

  1. In this mode, the module listens to and comprehends speech input, providing appropriate responses.

  2. Entering Chat Mode: Speak the wake-up word or short-press the right button to enter chat mode.

NOTE

When not in chat mode, short-pressing the right button still prompts the model to listen, comprehend, and respond appropriately, but the display remains outside the chat interface.

(2) Operation Instructions ​

  1. After completing network configuration, the module opens the expression interface by default, as shown below:

  1. Speak the designated wake-up word Hello Hiwonder, or short-press the right button, Button B, to enter chat mode. The buzzer sounds a tone to indicate successful activation, and the module begins listening.

  2. When entering chat mode via wake-up word, the module automatically sends Hello as an opening prompt on behalf of the conversational partner. The model displays and speaks a greeting, which can be interrupted to skip ahead as detailed in 6.6.8 Free Chat. The module then begins listening for incoming speech.

  1. When entering chat mode by short-pressing the right button, the module begins listening immediately.
  1. While interacting in chat mode, the interface can be toggled to hide the chat box and maintain the expression interface continuously. For detailed instructions, refer to the operational guide in 6.6.5 Expression Mode.

6.6.5 Expression Mode ​

NOTE

  • The module operates in Expression Mode while toggling modes with the left button. Short-pressing the left button to switch to Chat Mode does not wake up the module or activate live dialogue.

  • Specifically, if the display mode is set to "Chat Mode" via the left button, activating the module via wake-up word or the right button opens the chat box interface displaying the model's text responses.

  • If the display mode is set to "Expression Mode" via the left button, activating the module via wake-up word or the right button keeps the screen on the expression interface. The module mimics expressions appropriate to the response while displaying subtitles at the bottom of the screen.

(1) Mode Overview ​

  1. In this mode, the module simulates expressive facial reactions.

  2. Methods for entering expression mode: ① Double-tap the screen in camera mode to enter expression mode, and ② Short-press the right button in chat mode, while the module is not speaking, to enter expression mode.

(2) Operation Instructions ​

  1. In expression mode, short-press the left button to toggle between Chat Mode and Expression Mode. The active mode is indicated at the top of the screen.
  1. After toggling to Expression Mode via the left button, which configures the display to remain on facial expressions during chat, and activating the module via wake-up word or the right button, the module displays expressive reactions corresponding to dialogue. Common invocation approaches include: ① Describing a specific scenario, prompting the module to respond with an appropriate facial expression, and ② Requesting a specific expression, such as "Can you make a happy face?"

6.6.7 Camera Mode ​

(1) Mode Overview ​

  1. In this mode, the module activates the camera to continuously capture and display real-time images.

  2. Methods for entering camera mode: ① Double-tap the screen in expression mode to enter camera mode. Direct switching from chat mode to camera mode is not supported.

(2) Operation Instructions ​

  1. Double-tap anywhere on the screen in expression mode to switch to camera mode.

  1. In camera mode, the module continuously captures and displays real-time camera imagery. Without additional interaction, the module remains in this mode.

  2. Single-tapping anywhere on the screen in camera mode triggers the scene understanding feature, as detailed in 6.6.9 Scene Understanding.

6.6.8 Free Chat ​

(1) General Operation ​

  1. Once the module is powered on and connected to the network, wake the module by speaking the wake-up word or short-pressing the right button to enter chat mode.

  2. Speak freely during interaction. The module communicates with cloud-based large models to comprehend input and respond via text and voice. Featuring contextual memory, the module supports continuous multi-turn dialogue.

  3. After each conversational turn (including initial wake-up), the module continues listening. If no speech is detected for 2 consecutive minutes, listening terminates automatically, and the model announces a farewell phrase in the chat interface. To resume interaction, wake the module again by speaking the designated wake-up word or short-pressing the right button.

  4. The WonderLLM module supports voice interruption. While the module is speaking, including ① Voice replies to speech, ② Spoken greetings, and ③ Spoken farewells, short-pressing the right button immediately halts speech output and resumes listening for the next round of input.

  5. The WonderLLM module supports bilingual recognition and speech in Chinese and English. Switch the operating language directly using phrases such as: ① "Can you speak Chinese with me?" or ② "Can we speak English?"

6.6.9 Scene Understanding ​

NOTE

  • The scene understanding feature does not support continuous observation. It captures and analyzes a single real-time image upon receiving an activation command.

  • In camera mode, double-tapping the screen returns to the expression interface.

  • Before a single tap triggers the feature in camera mode, the module only captures and displays live camera imagery without invoking large models for analysis.

(1) Voice-Controlled Trigger ​

  1. Power on the module to enter the expression interface. Speak the wake-up word or short-press the right button to enter the chat interface and activate the module.

  2. Command the WonderLLM module using phrases such as: ① "Describe what you see in front of you," or ② "Take a photo, please."

  3. Once the command is processed, the camera captures a still image and displays it briefly for confirmation. The chat window displays the invoked image capture function, followed by a generated analytical description displayed and announced via speech, with responses dynamically generated to ensure appropriate phrasing.

(2) Touchscreen Trigger ​

  1. In expression mode, double-tap anywhere on the screen to enter camera mode. The screen displays the live camera view.
  1. In camera mode, single-tap anywhere on the screen. The camera captures a still image, displays it briefly for confirmation, and returns to camera mode. The module automatically announces its analysis of the captured scene, with responses dynamically generated to ensure appropriate phrasing.
